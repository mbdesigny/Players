# Adhan audio

Self-hosted adhan recordings played automatically at prayer time.

- `adhan.mp3` — general adhan (Abdul Basit Abdul Samad), used for all prayers
- `adhan-fajr.mp3` — Fajr adhan (Abu Hazim), used for Fajr only

Source: [mohsalvi/adhan-audio](https://github.com/mohsalvi/adhan-audio)
(`general/abdul-basit-abdul-samad-01.mp3`, `fajr/abu-hazim-fajr-01.mp3`).

Replace these files (keeping the same names) to change the adhan voice.
